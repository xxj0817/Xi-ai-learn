# quiz-generation Specification

## Purpose

把研究 Agent 收集到的参考资料与学习输入转换成结构化闯关题库，让每道题都能追溯到具体来源，并在检索不可用时保持可用的降级体验。

## Requirements

### Requirement: 使用研究结果规范化主题

当研究结果提供了规范化主题时，系统 SHALL 用它作为题库标题、摘要与出题主题。当 user_input 只包含网址时，MUST 使用页面内容推导出的主题，MUST NOT 把 URL 字符串当作主题。研究结果没有主题时，MUST 回退到清洗后的用户输入。

#### Scenario: 网址输入的主题规范化

- **WHEN** 用户只输入 `https://example.com/harness-engineering`
- **THEN** 题库标题与出题主题来自该页面的内容主题，而不是 URL 字符串

#### Scenario: 新概念主题规范化

- **WHEN** 用户输入 `Harness Engineering`，研究结果将它规范化为 AI Agent 工程实践
- **THEN** 题库标题、摘要与题目都围绕该规范化主题

#### Scenario: 研究结果缺少主题

- **WHEN** 研究结果为空或没有返回主题
- **THEN** 系统回退使用清洗后的用户输入作为主题

### Requirement: 基于参考资料出题

当存在参考资料时，系统 SHALL 只依据这些资料生成题目与讲解，MUST NOT 输出资料无法支撑的事实；资料与模型自身记忆冲突时 MUST 以资料为准。当没有任何参考资料时，系统 SHALL 使用模型自身知识出题，不得拒绝请求。

#### Scenario: 有资料时按资料出题

- **WHEN** 参考资料明确说明某概念的定义与用途
- **THEN** 生成题目的题干、正确选项与讲解均与该资料一致，不出现资料之外的事实断言

#### Scenario: 资料与模型记忆冲突

- **WHEN** 资料给出的定义与模型训练记忆中的常见说法不同
- **THEN** 题目按资料的定义判定正确答案，并在讲解中说明依据

#### Scenario: 无资料时用模型知识出题

- **WHEN** 研究被跳过、无结果或全部失败
- **THEN** 系统仍返回结构完整的题库，并把核实状态标记为仅模型知识

### Requirement: 同名不同义概念不混用

当用户输入是一个与既有领域同名、但实际属于新领域的概念时，系统 MUST 把题目限定在资料所指的领域内，MUST NOT 使用同名概念的其它领域事实作为正确答案。

#### Scenario: 新概念不被张冠李戴

- **WHEN** 用户输入 `Harness Engineering`，而资料指向 AI Agent 工程实践
- **THEN** 生成的题干、选项与讲解都围绕 AI Agent 工程实践，不出现软件测试夹具等其它领域知识

#### Scenario: 资料无法判定领域

- **WHEN** 检索结果与输入主题明显不相关或彼此矛盾
- **THEN** 系统仍返回题库，并在 grounding 的证据字符数中体现来源不足，而不是把无关内容当作权威答案

### Requirement: 每题引证

每道题 SHALL 输出 citations 字段，列出支撑该题答案的来源编号。citations MUST 使用本次题库中真实存在的来源编号，MUST NOT 出现虚构编号。

#### Scenario: 题目携带有效引证

- **WHEN** 系统基于来源 S1 与 S3 生成一道题
- **THEN** 该题的 citations 为 S1、S3 的子集，且每个编号都能在 sources 中找到

#### Scenario: 题目引用了不存在的来源

- **WHEN** 模型输出的引证包含 sources 中不存在的编号
- **THEN** 系统判定该题引证不合法，并移除不存在的编号

### Requirement: 引证校验与重试

系统 SHALL 校验每道题的引证；当存在无引证或引证非法的题目时，MUST 使用更严格的提示词重试一次。重试后仍不合格时，系统 MUST 保留题目、剔除非法引证，并把核实状态降级为部分核实，不得把不合格结果当作完整核实返回。

#### Scenario: 首次引证不合格触发重试

- **WHEN** 首次生成中有题目缺少引证或引用了虚构编号
- **THEN** 系统带严格约束重新生成，且重试请求中携带更强的引证要求

#### Scenario: 重试后仍不合格

- **WHEN** 重试后仍有题目缺少有效引证
- **THEN** 系统返回题库，剔除非法引证，并把核实状态标记为部分核实

#### Scenario: 全部引证合法

- **WHEN** 每道题都引用了真实来源
- **THEN** 核实状态为已核实，不触发引证相关的重试

### Requirement: 题库接口返回来源与核实状态

生成接口 SHALL 返回题库级 sources 与 grounding 信息。grounding MUST 包含核实状态、研究服务标识、检索时间与证据字符数；状态取值限定为已核实、部分核实、仅模型知识三种。新增字段 MUST 为可选或带默认值，保证旧客户端无需修改即可继续解析。

#### Scenario: 完整响应字段

- **WHEN** 客户端请求生成题库且研究成功
- **THEN** 响应包含 sources 列表与 grounding 对象，grounding 状态为已核实或部分核实，检索时间可读

#### Scenario: 旧客户端兼容

- **WHEN** 旧客户端只读取原有字段（quiz_id、title、summary、questions）
- **THEN** 响应仍包含这些字段且结构不变，新增字段不影响解析

### Requirement: 静默降级

当研究 Agent、检索服务或工具调用不可用、超时或返回空结果时，系统 MUST 继续完成出题，MUST NOT 向用户返回检索相关的错误提示；降级事实 MUST 记录在日志与 grounding 状态中，便于排查。

#### Scenario: Agent 超时

- **WHEN** 研究 Agent 超过配置的总超时
- **THEN** 用户仍收到正常题库，grounding 状态为仅模型知识或基于已采集来源的部分核实，日志包含超时原因

#### Scenario: 未配置检索凭据

- **WHEN** 检索凭据缺失
- **THEN** 用户仍收到正常题库，且系统未发起任何外部检索请求

### Requirement: 来源与核实状态持久化

对于已登录用户，系统 SHALL 把来源与核实状态随题库一起保存，并在闯关详情接口中返回；未登录或无持久化的场景 MUST 不影响出题结果返回。

#### Scenario: 详情接口返回来源

- **WHEN** 已登录用户生成题库后查询该题库详情
- **THEN** 详情中包含与生成时一致的 sources 与 grounding

#### Scenario: 历史数据没有来源

- **WHEN** 查询一个在本变更之前生成的历史题库
- **THEN** 详情正常返回，sources 为空列表、grounding 为仅模型知识的默认值

### Requirement: 既有出题契约保持不变

输入长度校验、敏感词过滤、题目数量范围、题型分布、选项与答案结构校验、失败重试次数与错误码 MUST 保持现有行为；参考资料能力不得放宽或绕过这些约束。

#### Scenario: 超长输入仍被拒绝

- **WHEN** user_input 超过配置的最大长度
- **THEN** 接口仍返回原有的参数错误响应，不因启用研究 Agent 而改变

#### Scenario: 题型分布仍被校验

- **WHEN** 模型返回的题型分布不满足要求
- **THEN** 系统仍按原有规则判定格式错误并重试
