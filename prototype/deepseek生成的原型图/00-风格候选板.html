鱼皮 AI 闯关学习小程序 · 原型阶段 0

UI 风格候选板 v0.1

从《阿衰》的漫画气质出发，我把它拆成三件可落地的东西：分镜感、纸张感、批改感。 下面三个方向用同一套核心三屏（首页 / 答题 / 答对反馈）做对照，方便你直接比出"味道"。

  • 画布 9 : 17.4 竖屏 · 模拟微信小程序
  • 排列 一行三列 · 980px / 640px 断点降级
  • 本期只做风格确认，不做业务页面
  • 字体：站酷快乐体 / 庆科黄油体 / 楷体兜底
① 同类产品调研结论 ② 方案 A 漫格 ③ 方案 B 草稿本 ④ 方案 C 闯关 ⑤ 对比与推荐 ⑥ 页面地图与文件拆分

一句话定位

三个方向都不是"可爱贴纸风"，而是把漫画的叙事结构搬进界面：分镜 = 信息层级，拟声词 = 状态反馈，红笔 = 批改与鼓励。

A

漫格 · 油墨四格

最像《阿衰》。粗黑描边 + 网点纸 + 硬投影，界面就是一本四格漫画。

个性最强记忆点高密集信息需克制
B

草稿本 · 练习纸

最像"学习"本身。横线本 + 红笔批注 + 荧光笔，安静但极有代入感。

耐看报告/海报强游戏感偏弱
C

闯关 · 潮漫 3D

最像主流闯关 App。厚描边 + 实体按压按钮 + 高饱和，转化率最稳。

手感最好上手零成本略常见

同类产品在用什么视觉语言

我把回答类 / 学习类产品分成四类"血缘"。结论先放这里：答题产品的形态已经高度同质化（白底卡片 + 高饱和强调色），差异化只能从"叙事方式"上找。

产品 视觉语言 值得借的 不该借的
Duolingo
游戏化学习标杆		 亮绿 #58CC02 主色、圆头字形、按钮底部 4px 实色"厚度"、关卡路径地图、连胜火焰与宝石 按钮的物理按压手感；答对瞬间的强反馈；把"坚持"做成可视化资产 重吉祥物依赖；欧美卡通脸与中文学习语境有距离
Kahoot!
课堂抢答		 紫 #46178F 底 + 四色答案块（红黄蓝绿 × 形状 ▲◆●■）、超大字号、几乎无装饰 颜色 + 形状双重编码（色弱友好）；选项本身就是界面主角 为投屏/多人场景设计，单手竖屏会很空旷
Quizizz / Wayground
学生自测		 紫 #8854C0、卡片流、头像与表情贴纸、梗图化表达 用"梗"降低挫败感；头像/昵称让单人做题不孤单 贴纸滥用会显得廉价，且不利于沉淀"知识档案"的专业感
百词斩 / 扇贝
中文记忆类		 一图一义、插画 + 白底、橙蓝点缀、进度天梯 用图像承担记忆锚点；每日任务的心智极轻 纯文本 MVP 阶段无法照搬"一题一图"，需用排版补足画面感
猿题库 / 粉笔
中文应试答题		 白底大留白、A/B/C/D 圆角序号块、红绿判题、解析折叠 中国用户已经训练出来的答题器范式，学习成本几乎为零；解析折叠控页长 过于"应试"，会把"闯关"的趣味稀释成"刷题"
微信读书
阅读类		 米黄纸色、衬线正文、极简细线、大面积留白 "纸"的底色能压住花哨，让长文本（AI 讲解）舒服 缺少即时反馈的爽感，需要叠加游戏化层
小红书知识卡片
分享裂变		 奶油底 + 手写标题 + 胶带/贴纸/边框、竖版 3:4 封面 海报的"手作感"是分享率的关键，机器感越强越没人转 信息密度低，不适合承载报告数据
空位在哪：大家要么"像游戏"（Duolingo / Kahoot），要么"像试卷"（猿题库 / 粉笔）， 要么"像笔记"（微信读书）。没有人把「漫画分镜」当成信息结构来用—— 题目是一格、讲解是旁白框、对错是拟声词与红笔批改。这正是《阿衰》能给我们的、别人抄不走的差异点。

我的推荐：A 当骨架，B 做纸底，C 借手感 —— 一个"混血"方案。
具体分工：
· 首页 / 闯关页 / 反馈 → 用 A：分镜格 + 拟声词 + 红笔，个性最强，是记忆点所在；
· 底色与长文本 → 掺 B：纸黄底 + 楷体批注，压住 A 在长文页的躁；
· 按钮与 XP/进度 → 掺 C：3px 厚描边 + 实色底影 + 按下位移，手感统一且开发最省；
· 报告 / 海报 → 全用 B：试卷批改 + 单行本封面，天然适合晒朋友圈。
这样既不会像"又一个 Duolingo"，也不会因为过度漫画化而牺牲可读性。
