# 鱼皮 AI 闯关学习小程序

把「任意一句话 / 文档 / 网页 / 视频」交给 AI，自动生成交互式问答闯关题库，答题过程中即时给出正确答案与知识讲解，通关后生成知识总结与复盘报告。

当前仓库处于 **需求与方案设计阶段**，包含需求分析文档与多套高保真原型稿。

## 核心闭环（MVP）

1. 用户输入想学的知识（一句话 / 一段文本）
2. AI 联网检索或直接解析内容，生成题目、选项、答案与解析
3. 用户逐题闯关，选择后立即获得正误反馈与知识讲解，并累计经验值
4. 通关后生成正确率、知识总结与掌握度报告，可生成分享海报
5. 后台沉淀学习记录，支持错题复盘与旧识重温

## 技术方案要点

- **前端**：微信小程序原生方案，页面为首页输入、闯关页、报告页
- **后端**：FastAPI + LangChain 作为 AI 接入层
- **模型**：DeepSeek，使用 JSON 输出 + 校验重试保证题库结构稳定
- **存储**：MVP 阶段以轻量存储为主，后续演进到 RAG 私有知识库
